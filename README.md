# React-Practice1 🚀

Pequeño proyecto de práctica con React que sirve como base para aprender y experimentar con componentes, estado y estilo.

---

## 📦 Instalación

```bash
# Clona el repositorio
git clone https://github.com/VenomJD/React-Practice1.git

# Entra en la carpeta del proyecto
cd React-Practice1

# Instala las dependencias
npm install
# o
yarn install
```

---

## ⚙️ Uso

```bash
# Inicia el servidor de desarrollo
npm start
# o
yarn start
```

Abre http://localhost:3000 en tu navegador. La página recargará cada vez que guardes cambios en el código.

---

## ✨ Estructura del proyecto

- **`src/`**: Código fuente principal
  - `App.js` – Componente principal de la aplicación
  - `index.js` – Punto de entrada y montaje de App
  - `components/` – Componentes reutilizables
  - `styles/` – Archivos CSS o preprocesadores
- **`public/`**: Assets estáticos (HTML, imágenes, etc.)

---

## 🔧 Tecnologías usadas

- **React** (hooks, JSX)
- **React Router** (si se utiliza navegación)
- **CSS Modules / Styled Components / Tailwind** (según corresponda)
- **ESLint** y **Prettier** para mantener consistencia de código

---

## 🛠 Características

- Renderizado de componentes funcionales
- Manejo de estado con `useState`
- (Opcional) Routing con `react-router`
- Responsive design y estilos limpios
